# Gabarito Comentado — Bloco `F05` (Hipérbole na Origem e Assíntotas)

> **Bloco de referência:** [F05_bloco.md](../blocos/F05_bloco.md)

## 1. Exercícios

### `F05-E01` *(Hipérbole na origem, eixo horizontal)*
- **Passo a passo:**
  - `x²/9 - y²/16 = 1`. Termo positivo sob `x²` → eixo real horizontal.
  - `a = 3`, `b = 4`.
  - `c = √(a² + b²) = √(9 + 16) = 5`. Focos `(±5, 0)`.
  - `e = c/a = 5/3`.
- **Resposta Final:** `(a) horizontal (b) (+-5, 0) (c) e = 5/3`
- **Alerta pedagógico:** Na hipérbole, `c = √(a² + b²)` (MAIS, não menos como na elipse).

---

### `F05-E02` *(Hipérbole na origem, eixo vertical)*
- **Passo a passo:**
  - `y²/25 - x²/144 = 1`. Termo positivo sob `y²` → eixo real vertical.
  - `a = 5`, `b = 12`.
  - `c = √(25 + 144) = 13`. Focos `(0, ±13)`.
  - Assíntotas: `y = ±(a/b)x = ±(5/12)x`.
- **Resposta Final:** `(a) vertical (b) (0, +-13) (c) y = +-5/12 x`
- **Alerta pedagógico:** Para eixo vertical, assíntotas são `y = ±(a/b)x` (note `a` no numerador).

---

### `F05-E03` *(Hipérbole equilátera)*
- **Passo a passo:**
  - `x² - y² = 25` → `x²/25 - y²/25 = 1`. `a² = 25 → a = 5`, `b² = 25 → b = 5`. `a = b` → equilátera.
  - `c = √(25 + 25) = √50 = 5√2`.
  - `e = c/a = 5√2/5 = √2`.
  - Assíntotas: `y = ±x`.
- **Resposta Final:** `(a) a=5, b=5 (b) e = √2 (c) y = +-x`
- **Alerta pedagógico:** Hipérbole equilátera tem `a = b`, assíntotas `y = ±x`, excentricidade `√2`.

---

### `F05-E04` *(Dados a e b, encontrar equação e focos)*
- **Passo a passo:**
  - `a = 4`, `b = 3`, eixo horizontal.
  - Equação: `x²/16 - y²/9 = 1`.
  - `c = √(16 + 9) = 5`. Focos `(±5, 0)`.
- **Resposta Final:** `(a) x²/16 - y²/9 = 1 (b) (+-5, 0)`
- **Alerta pedagógico:** `c = √(16 + 9) = 5`, terna pitagórica (3, 4, 5).

---

### `F05-E05` *(Integração: assíntotas e excentricidade)*
- **Passo a passo:**
  - `y²/16 - x²/9 = 1`. Eixo vertical (`y²` positivo).
  - `a = 4`, `b = 3`.
  - **(a)** Assíntotas: `y = ±(a/b)x = ±(4/3)x`.
  - `c = √(16 + 9) = 5`. **(b)** `e = c/a = 5/4`.
- **Resposta Final:** `(a) y = +-4/3 x (b) e = 5/4`
- **Alerta pedagógico:** Eixo vertical → assíntotas `y = ±(a/b)x` com `a` do termo positivo.

## 2. Checagem Independente

### `F05-C01` *(Hipérbole, eixo horizontal)*
- **Passo a passo:**
  - `x²/25 - y²/9 = 1`. `a = 5`, `b = 3`.
  - `c = √(25 + 9) = √34`.
  - `e = c/a = √34/5`.
- **Resposta Final:** `(a) c=√34 (b) e = √34/5`
- **Alerta pedagógico:** `c = √34` não simplifica. `e = √34/5` é radical exato.

---

### `F05-C02` *(Assíntotas)*
- **Passo a passo:**
  - `x²/4 - y²/9 = 1`. Eixo horizontal.
  - `a = 2`, `b = 3`.
  - Assíntotas: `y = ±(b/a)x = ±(3/2)x`.
- **Resposta Final:** `y = +-3/2 x`
- **Alerta pedagógico:** Eixo horizontal → assíntotas `y = ±(b/a)x` com `b` no numerador.

---

### `F05-C03` *(Hipérbole equilátera)*
- **Passo a passo:**
  - `x² - y² = 9` → `x²/9 - y²/9 = 1`. `a = b = 3`. Equilátera.
  - `c = √(9 + 9) = √18 = 3√2`.
  - `e = c/a = 3√2/3 = √2`.
  - Assíntotas: `y = ±x`.
- **Resposta Final:** `(a) e = √2 (b) y = +-x`
- **Alerta pedagógico:** Toda hipérbole equilátera tem `e = √2` e assíntotas `y = ±x`.
